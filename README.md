# elle-e-lee.com

Source code for my portfolio site: [elle-e-lee.com](https://elle-e-lee.com)

I'm Elle Lee, a digital designer and art director in New York.

## How it's built

- Static HTML, CSS and JavaScript. No framework and no build step.
- Each page is a single file with its styles and scripts inline.
- Designed and built with Claude.
- Hosted on Cloudflare Pages.
- Fonts: Host Grotesk, Schibsted Grotesk and Bodoni Moda, loaded from Google Fonts.
- Visitor analytics: Microsoft Clarity.
